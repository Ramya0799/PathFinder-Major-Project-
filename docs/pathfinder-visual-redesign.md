# PathFinder Visual Redesign

## Scope

This refinement follows the supplied visual brief as a presentation-only update. The existing routing graph, map, 3D, AR, VR, assistant, voice, authentication, database, and API contracts remain unchanged.

## Visual direction

PathFinder now uses a deep navy and AIET-blue hero treatment with restrained cyan route cues and warm gold actions. The landing page keeps the existing warm academic surfaces below the hero so the institutional identity remains present while the first screen reads as a navigation product.

The hero communicates the supplied message, “Never Get Lost at AIET Again.” It uses the existing real AIET campus media and adds a low-contrast wayfinding layer made of route segments, nodes, and labels. The layer is decorative orientation language only; it does not represent surveyed coordinates or a new route.

The primary hero actions are Start navigation, Explore campus, View in 3D, and AR navigation. They reuse the existing route handoff and page paths. The existing full route planner remains available below the compact action group.

The campus photograph archive retains all user-supplied images with accessible captions and source filename context. Only Main Gate, Central Library, and Computer Science Department cards expose existing PathFinder route destinations. Interior photographs, the New Building photographs, walkways, and other visual landmarks remain discovery-only until campus-authorised survey data is supplied.

## Preserved behavior

No new coordinates, floor assignments, route edges, indoor markers, building geometry, or destination IDs are inferred from the supplied brief. The redesign changes hierarchy, color, motion cues, and presentation while retaining existing route calculations and navigation handoffs.
